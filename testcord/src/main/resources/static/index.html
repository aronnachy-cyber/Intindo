Discord-Compatible API Platform

Build bots on Testcord

A self-hosted Discord-compatible gateway. Connect your bots using the same token system, REST API, and WebSocket gateway as Discord — just point to your server.

🔌

WebSocket Gateway

Bots connect via WebSocket and receive real-time events: MESSAGE_CREATE, GUILD_MEMBER_ADD, GUILD_MEMBER_REMOVE, and more.

ws://your-host/gateway
🌐

REST API

Full Discord-compatible REST endpoints for sending messages, managing members, banning users, and more.

POST /channels/{id}/messages
GET /guilds/{id}/members
DELETE /guilds/{id}/members/{id}
🔑

Bot Token Auth

Issue bot tokens to authenticate. Bots send Authorization: Bot <token> just like Discord.

Authorization: Bot MTExMTEx.xxxxx
🔐

OAuth2

Full OAuth2 authorization code flow for dashboard logins. Compatible with Discord OAuth2 libraries.

GET /oauth2/authorize
POST /oauth2/token
