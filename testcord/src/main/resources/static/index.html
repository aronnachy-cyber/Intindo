🚀 Quick Start Guide

Step-by-step

  1. Register a user account — go to the Dashboard → Auth tab, enter a username and password, and click Register.
  2. Create a bot — in the Auth tab, type a bot name (e.g. SP4RK) and click Create Bot. Copy the token that appears — you'll need it.
  3. Create a guild — go to the Guilds tab, enter a server name, and click Create Guild. Copy the Guild ID from the response.
  4. Create a channel — use the API Tester tab to call POST /guilds/{guildId}/channels with body {"name":"general"}. Copy the Channel ID from the response.
  5. Connect your bot via WebSocket — point your bot library at this server. For Eris / discord.js set the gateway URL and REST base URL below.
  6. Send a message — go to the Channels tab, paste the Channel ID, type a message, and click Send. Your bot will receive a MESSAGE_CREATE event over the gateway.

Connecting SP4RK (or any bot) — code examples

Replace YOUR_TOKEN with the token you got in step 2 and YOUR_HOST with your server URL.

▸ Eris (Node.js)

// npm install eris const Eris = require('eris'); const bot = new Eris('Bot YOUR_TOKEN', { rest: { baseURL: 'https://YOUR_HOST' }, ws: { gateway: 'wss://YOUR_HOST/gateway' } }); bot.on('messageCreate', (msg) => console.log(msg.content)); bot.connect();

▸ discord.py (Python)

# pip install discord.py aiohttp import discord, aiohttp class TestcordClient(discord.Client): async def setup_hook(self): self.http.BASE = 'https://YOUR_HOST' client = TestcordClient() client.run('YOUR_TOKEN')

▸ Raw WebSocket (any language)

# 1. Connect to: wss://YOUR_HOST/gateway # 2. Receive: {"op":10,"d":{"heartbeat_interval":41250}} # 3. Send IDENTIFY: {"op":2,"d":{"token":"Bot YOUR_TOKEN","intents":513}} # 4. Receive READY: {"op":0,"t":"READY","d":{"user":{...},"guilds":[...]}} # 5. Send HEARTBEAT every 41s: {"op":1}

⚙️ Environment Variables for Deployment
⚠️ Before deploying: At minimum you must set JWT_SECRET to a long random string. Never use the default value in production.
VariableDefault (dev)Description
JWT_SECRET REQUIRED testcord-super-secret-key-… Secret key used to sign bot tokens. Must be at least 32 characters. Generate one with: openssl rand -base64 48
PORT optional 5000 HTTP port the server listens on. Most platforms set this automatically.
DB_URL optional jdbc:h2:file:./testcord-db JDBC connection URL. For PostgreSQL use: jdbc:postgresql://host:5432/testcord
DB_DRIVER optional org.h2.Driver JDBC driver class. For PostgreSQL: org.postgresql.Driver
DB_DIALECT optional org.hibernate.dialect.H2Dialect Hibernate dialect. For PostgreSQL: org.hibernate.dialect.PostgreSQLDialect
DB_USERNAME optional sa Database username.
DB_PASSWORD optional (empty) Database password.
APP_URL optional http://localhost:5000 Public URL of your deployment. Used in OAuth2 redirect URLs. Example: https://testcord.replit.app
APP_NAME optional Testcord Platform display name.
JWT_EXPIRATION_MS optional 86400000 OAuth2 access token lifetime in milliseconds. Default = 24 hours.
H2_CONSOLE_ENABLED optional true Set to false in production to disable the H2 database web console.

💡 On Replit: go to Secrets (lock icon in sidebar) and add each variable there. On other platforms set them as environment variables before starting the server.

Minimal production config (copy-paste into Replit Secrets)

# REQUIRED JWT_SECRET=replace-this-with-64-random-chars-from-openssl-rand-base64-48 # Optional: switch to PostgreSQL (Replit DB) DB_URL=jdbc:postgresql://host:5432/testcord DB_DRIVER=org.postgresql.Driver DB_DIALECT=org.hibernate.dialect.PostgreSQLDialect DB_USERNAME=your_pg_user DB_PASSWORD=your_pg_password # Recommended in production APP_URL=https://your-app.replit.app H2_CONSOLE_ENABLED=false
